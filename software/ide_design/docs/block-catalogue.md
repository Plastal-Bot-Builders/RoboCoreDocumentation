# RoboCore IDE — block catalogue

The Blocks editor’s block set: hardware-first blocks for the RoboCore V2, in the spirit of LEGO SPIKE Prime’s word blocks (the ideas, not their art). Blocks name what the robot does; each action has a “for …”, a “start …” and a “stop” form; each sensor has a value, a yes / no question and a “when …” hat.

74 blocks in 10 categories; 31 need a new helper in the RoboCore library (firmware/RoboCore). Generated from `figma-plugin/src/05a_block_data.js` by `node tools/blocks_md.js`; do not edit this file by hand. In Figma: page 02 (Blocks family), page 01 (Blocks), page 07 (Block catalogue).

Notation: [dropdown] (number) “text” < > empty yes / no slot.
