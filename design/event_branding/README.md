# RoboCore — event branding

**Figma file:** [RoboCore — Event Branding](https://www.figma.com/design/TQeCbCn60mNwvgoOme5AAI) (Drafts, Plastal-Bot Builders team).

These are print pieces for expos and public events. RoboCore leads, and "by Plastal-Bot Builders" sits small as the maker. The look is the RoboCore V2 box: navy ink, RoboCore yellow, cream paper, topographic contour lines, Barlow Condensed Bold headlines and the yellow robot on navy.

## Printing

- **True size:** every artboard is set up at true size (1 unit = 1 pt). Select an artboard and use **Export as PDF**: the PDF comes out at the printed size, bleed included.
- **Guides:** each artboard has a hidden **Guides** layer showing the trim line (red) and the safe area (blue). Turn it on to check a change.
- **Colour:** Figma exports RGB PDFs, so ask the printer for a proof. The brand kit gives starting CMYK values and the closest Pantone for navy and yellow.
- **Pop-up stand size:** pop-up stand sizes vary between suppliers. Get their template first, then resize the artboard and move the right-hand elements.
- **QR code:** it links to `https://www.plastalbotbuilders.com` (the www is needed). It's always navy on a white tile with a quiet zone. Keep it at least 25 mm wide on paper and 150 mm on banners.

## Copy rules

- Say "designed in Zambia", never "made in Zambia".
- RoboCore V2 is a prototype; pilots with schools and innovation hubs come next.
- Impact line: "Our team has been part of initiatives that have reached more than 8,000 young people in Zambia."
- All copy lives in `COPY` in `figma-plugin/src/02_parts.js`, so every piece says the same thing.

## How it's built

The pieces are generated by a Figma development plugin, **RoboCore Event Branding Builder** (`figma-plugin/`).

- `src/01_base.js`: units (mm to pt), the Brand colour variables, Barlow fonts, and drawing helpers.
- `src/02_parts.js`: copy, logos (the RoboCore box lockup and the Plastal-Bot logo, both vector), the QR tile, Lucide icons, coding blocks (the IDE's Blockly shapes), the IDE illustration (blocks plus the C++ they write) and pillars.
- `src/03_formats.js`: the five pieces. `src/04_brandkit.js`: the brand kit. `src/09_main.js`: pages and review exports.
- `src/00_assets_gen.js`: generated by `node tools/gen_assets.js` from `assets/` (logos, QR) and the IDE design builder (box contour lines, icons, the Geared Ring).

Raster artwork lives in `assets/` and is served to the plugin by `test/server.py`:

- `renders/`: orthographic studio renders of RoboCore V2 (Fusion v36) and its box, on transparent backgrounds with a soft floor shadow, about 2,600 px on the long side.
  - Robot: `robot_iso_fl` (the hero on every piece), `iso_fr`, `iso_rr`, `front`, `back`, `left`, `right`, `top`.
  - Box: `box_closed_iso_fl`, `iso_fr`, `front`, `top`; `box_open_iso_fl`, `iso_fr`.
- The robot line drawing, from the box art. `robot_hero.png` is the older perspective render, no longer used.

The front, side and top renders make up the **views strip**: the three views drawn at the same scale, with real dimensions (167 × 278 × 118 mm). On the pop-up stand it prints at actual size.

### Renders

1. Export the robot from Fusion as STEP into `3d/`, then convert it to GLB: `uv run --offline --no-project --python 3.12 --with cadquery-ocp python -I step2glb.py in.step out.glb 0.03`. The box GLBs come from `RoboCore/mechanical/robot_v2/packaging/out/`.
2. Render with Blender (Cycles, orthographic camera, transparent film, shadow catcher): `Blender -b --python 3d/render_views.py -- robot iso_fl,front,top 3d/renders_raw 2400 64`. The subject is `robot`, `box_closed` or `box_open`.
3. Finish them for print: `python3 -I 3d/finish_renders.py`. It reads `3d/renders_raw/` and writes `assets/renders/`. The shadow fades out before the edge, the box top is turned upright, the straight-down views get no shadow, and the hero shots are trimmed.
4. Run `node figma-plugin/tools/gen_assets.js` to refresh the image sizes, then rebuild.

### Rebuild

1. Start the local server: `python3 -I figma-plugin/test/server.py review` (port 8767). It serves the images and receives review PNGs.
2. Rebuild the plugin bundle: `sh figma-plugin/build.sh`. For an offline dry run, use `node figma-plugin/test/run.js`.
3. In Figma, open Actions, search "RoboCore Event Branding", and run **Build / Rebuild the event pieces**. It replaces only its six pages.
4. Keep Figma in front and the Mac awake while it runs (about 15 seconds). A locked screen stalls Figma plugins.
