## Rebuilding the photo column
`mapping.json` (this folder) lists the photo and the cell comment for each line. `tools/costing/xlsx_photos.py IN.xlsx OUT.xlsx MAPPING.json` inserts a new column C with the thumbnails and shifts every formula, validation and the freeze pane one column to the right, so run it on a workbook **without** the Photo column; the file paths in MAPPING must be absolute or relative to where you run it. `contact_sheet.jpg` shows all 31 lines at a glance.
